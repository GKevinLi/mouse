This is the README for the project's CAD files. Relevant information and known issues will be documented here.

## How to Print:
Import the STEP files into your 3D printer slicer software of choice. For the shell, around 25% infill is recommended. Make sure to use supports as well.

For the scroll wheel, print it with the narrow end at the bottom. This increases the chance of a successful print. I use tree supports for this piece since they are easy to break off.

Only print the screw_spacers STEP file if the M2 screws you are using are too long to fit fully into the mouse PCB's mounting holes. Duplicate it a few times, since you will need some for every hole.

## Known Issues: 
- Upper shell print quality is bad. I do not know how to fix this at the moment, and I don't know if a better printer will help with this.
- Scroll wheel print is fragile and very inconsistent. I do not know how to fix this at the moment, but I have been experimenting with the design.
- Strange gaps in the bottom piece may appear. This is due to my CAD being somewhat imperfect, which will hopefully be fixed in the future.
- Some USB-C connectors may not fit in the USB-C cutout.
